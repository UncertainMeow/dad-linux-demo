# Demo runbook

## Setup

1. Create a new user account on the laptop (Settings → Users).
2. Log into the new account.
3. Clone this repo and run `scripts/bootstrap.sh`.

## How to narrate

- “None of this is required.”
- “This is what Linux looks like when you tinker a little.”
- “You can stop at email and web browsing and be totally happy.”
- “This is the fun layer.”

## The 10 minute sequence

1. Log in to the demo account.
2. Open Terminal.
3. Run the bootstrap script.
4. When fastfetch prints, pause.
5. Open Tweaks and bump text size slightly.
6. Pin apps to the dock (Browser, Files, Software, Photos).
7. Open Files, Browser, and a Terminal with `htop`.
8. Run `scripts/demo-screenshot.sh` and take the screenshot.

## What to avoid

- Deep terminal tutorials
- Anything that looks “hacky”
- Anything that might break his mental model

Goal: “curiosity is rewarded”, not “you must become a tinkerer”.
